BarcodeMate 0.5.3 adds an **update notice**, so a new release no longer depends on you thinking to check the website.

- Once a day the app asks barcodemate.com which version is current. When a newer one exists, a single line appears above the workspace with a link to the download page. It never covers what you are doing and is not a dialog.
- **Nothing is downloaded and nothing is installed.** The link opens the download page in your browser; what happens next is your decision, as it was before.
- The request says nothing about you: no identifier, no account, and not even the version you are running. The comparison happens on your computer, so the answer is identical for everyone and we cannot tell who asked. Access logging is disabled for that address, as it is for the usage counters.
- Dismissing the notice keeps it away for that version. A later release brings it back once.
- **About → Check for new versions** switches it off, and then the app makes no request of its own at all.

Updating still means downloading the installer and running it yourself. People already on 0.5.2 or earlier will not see this notice, because the version that checks is this one: they will learn about a new release the way they do now, by visiting the site.

The privacy page describes the check in all 24 languages.

Source commit: `SOURCE_COMMIT`. Validated Windows/macOS packages: https://github.com/barcodemate/desktop/actions/runs/SOURCE_RUN

Installers remain unsigned and macOS packages are not notarized.
